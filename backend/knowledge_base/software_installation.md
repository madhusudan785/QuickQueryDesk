# Software Installation Guide

## Overview
This guide covers how to request and install software on company devices. All software must be approved by IT before installation to ensure security compliance.

## Pre-Approved Software
The following software is available for self-service installation through the **Company Software Center**:

| Category        | Available Software                                    |
|-----------------|-------------------------------------------------------|
| Browsers        | Google Chrome, Mozilla Firefox, Microsoft Edge        |
| Communication   | Microsoft Teams, Slack, Zoom                          |
| Productivity    | Microsoft 365, Adobe Acrobat Reader, Notion           |
| Development     | VS Code, Git, Docker Desktop, Postman, Node.js       |
| Design          | Figma (web), Adobe Creative Cloud (requires license)  |
| Utilities       | 7-Zip, Notepad++, WinSCP, PuTTY                      |

### Self-Service Installation
1. Open the **Company Software Center** (pre-installed on all company devices).
2. Browse or search for the software you need.
3. Click **Install** and wait for the installation to complete.
4. No admin credentials required for pre-approved software.

## Requesting Non-Standard Software

If the software you need is not in the Software Center:

1. Submit a request through the IT portal at `https://itportal.company.com/software`.
2. Provide:
   - Software name and version
   - Business justification
   - License requirements (free, paid, or enterprise)
   - Link to the software vendor
3. IT Security will review the request within **3–5 business days**.
4. Approved software will be added to your Software Center or installed by IT.

## Prohibited Software
- Torrent clients or P2P file-sharing applications
- Unauthorized VPN or proxy tools
- Cryptocurrency mining software
- Unlicensed or pirated software

## License Management
- Software licenses are managed centrally by IT.
- Do not purchase software licenses independently — contact IT for procurement.
- Unused licenses are reclaimed after **90 days** of inactivity.

## Support
For software installation issues, contact IT Support at `it-support@company.com` or extension **4500**.
